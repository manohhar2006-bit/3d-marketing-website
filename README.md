# 🎧 Sony WH-1000XM6 3D Scrollytelling Experience

A premium Apple-inspired interactive product showcase built using Next.js, Framer Motion, Tailwind CSS, and a frame-sequence animation system.

This project recreates a cinematic Sony WH-1000XM6 product experience where users can explore the headphones through smooth scroll-based storytelling and interactive 3D-inspired effects.

---

## ✨ Features

* 🎬 Cinematic frame-sequence animation
* 🎧 Sony WH-1000XM6 product showcase
* 🖱️ Interactive cursor-based 3D effect (Overview section)
* 📜 Smooth scrollytelling experience
* 🌙 Premium dark Apple-inspired UI
* 🚀 Optimized canvas rendering
* 📱 Responsive design
* ⚡ Built with Next.js and Framer Motion

---

## 🛠️ Tech Stack

* Next.js
* React
* Tailwind CSS
* Framer Motion

## 📸 Frame Sequence Setup

Place all animation frames inside:

```bash
public/frames/
```

Example:

```bash
frame_0001.jpg
frame_0002.jpg
frame_0003.jpg
...
```

Ensure:

* Sequential naming
* Same resolution
* Optimized image size
* Consistent background
